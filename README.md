# SQL for Data Analysis: Learning Tracker & Scripts

##  Overview
This repository tracks my journey learning SQL for Data Analysis, focusing on MySQL. It contains scripts, queries, and exercises I have completed while working through various data analytics tutorials (including the Alex The Analyst SQL Bootcamp). The goal is to build a solid foundation in relational databases, data manipulation, and exploratory data analysis (EDA).

## Repository Structure
The SQL scripts in this repository are categorized by difficulty and core concepts:

### 1. Basics
*Fundamental query structures and filtering.*
- `01_select_statements.sql` - `SELECT`, `FROM`, `DISTINCT`, `LIMIT`
- `02_filtering_data.sql` - `WHERE`, `AND`, `OR`, `IN`, `LIKE`
- `03_grouping_and_ordering.sql` - `GROUP BY`, `ORDER BY`, Aggregate Functions (`COUNT`, `AVG`, `SUM`, `MAX`, `MIN`)
- `04_having_clause.sql` - Filtering grouped data using `HAVING`

### 2. Intermediate
*Combining data and advanced filtering.*
- `05_joins.sql` - `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL OUTER JOIN`
- `06_unions.sql` - `UNION`, `UNION ALL`
- `07_case_statements.sql` - `CASE WHEN` logic for categorizing data
- `08_updating_deleting.sql` - `UPDATE`, `DELETE`, `ALTER TABLE`
- `09_partition_by.sql` - Using `PARTITION BY` with aggregate functions

### 3. Advanced
*Complex query writing, subqueries, and database management.*
- `10_ctes.sql` - Common Table Expressions (CTEs) for readable complex queries
- `11_temp_tables.sql` - Creating and manipulating Temporary Tables
- `12_string_functions.sql` - `TRIM`, `REPLACE`, `SUBSTRING`, `UPPER`, `LOWER`
- `13_subqueries.sql` - Queries within queries (Select, From, and Where clauses)
- `14_stored_procedures.sql` - Automating repeated queries

### 4. Portfolio Projects
*Real-world datasets cleaned and analyzed using MySQL.*
- **Data Cleaning in SQL:** Taking raw, messy data and standardizing it (Handling NULLs, removing duplicates, standardizing formats).
- **Exploratory Data Analysis (EDA):** Finding trends, patterns, and outliers using aggregate functions and CTEs.
